# JobTrackerAPI 🚀

Job Application Tracker REST API built with ASP.NET Core (.NET 8).  
This project demonstrates REST API design, JWT authentication, and database management using Entity Framework Core.

---

## 📌 Features
- JWT Authentication
- User registration & login
- Job, Company, Application CRUD
- EF Core + SQL Database
- DTO + clean architecture

---

## 🛠 Tech Stack
- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server / MySQL
- JWT Authentication

---

## 📡 API Features
- Auth (Register/Login)
- Jobs management
- Companies management
- Applications tracking
